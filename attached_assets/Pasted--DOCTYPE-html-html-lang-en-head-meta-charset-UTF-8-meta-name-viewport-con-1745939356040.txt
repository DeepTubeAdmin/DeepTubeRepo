                        <div class="post-content mt-4">
                            <p class="mb-4">After months of experimentation, I've compiled my best prompts for creating photorealistic portraits in Midjourney v5. I thought I'd share my findings with the community.</p>
                            
                            <h3 class="font-bold mb-2">Basic Portrait Formula:</h3>
                            <p class="mb-4 bg-gray-800 p-3 rounded font-mono text-sm">portrait of [gender], [age], [ethnicity], [distinctive features], [emotion], [lighting], [camera details], photorealistic, hyperdetailed, 8k --ar 2:3 --v 5</p>
                            
                            <h3 class="font-bold mb-2">Example:</h3>
                            <p class="mb-4 bg-gray-800 p-3 rounded font-mono text-sm">portrait of a 40-year-old Scandinavian woman with freckles and auburn hair, contemplative expression, rembrandt lighting, shot on Hasselblad, 105mm lens, photorealistic, hyperdetailed, 8k --ar 2:3 --v 5</p>
                            
                            <p class="mb-4">The key aspects that have improved my results:</p>
                            <ul class="list-disc list-inside mb-4 space-y-1 text-gray-300">
                                <li>Specifying camera and lens details</li>
                                <li>Using photography lighting terminology (rembrandt, butterfly, split, etc.)</li>
                                <li>Being specific about emotions rather than generic "smiling"</li>
                                <li>The --ar 2:3 ratio works best for portraits</li>
                            </ul>
                            
                            <p>What are your best portrait prompts? I'd love to see what's working for everyone else!</p>
                        </div>

                            <p class="mb-4">Thanks for sharing these formulas! I've been struggling with getting consistent results for portraits.</p>
                            
                            <p class="mb-4">I've found that adding these parameters also helps a lot:</p>
                            <p class="mb-4 bg-gray-800 p-3 rounded font-mono text-sm">--stylize 25 --chaos 15</p>
                            
                            <p class="mb-4">The lower stylize value keeps it photorealistic while the chaos adds some creative variations. I'd recommend different chaos values (5-30) depending on how experimental you want to be.</p>
                            
                            <p>Also, specifying specific photographers can dramatically change the style: "in the style of Annie Leibovitz" or "in the style of Richard Avedon" gives very different but consistently good results.</p>

            const daySelect = document.getElementById('dobDay');
            
            if (yearSelect.value && monthSelect.value && daySelect.value) {
                const birthDate = new Date(yearSelect.value, monthSelect.value - 1, daySelect.value);
                const today = new Date();
                const age = today.getFullYear() - birthDate.getFullYear();
                const monthDiff = today.getMonth() - birthDate.getMonth();
                
                // Check if birthday has occurred this year
                if (monthDiff < 0 || (monthDiff === 0 && today.getDate() < birthDate.getDate())) {
                    age--;
                }
                
                // Check age requirement
                if (age < 18) {
                    document.getElementById('ageError').classList.remove('hidden');
                    return;
                }

            isLoggedIn = true;
