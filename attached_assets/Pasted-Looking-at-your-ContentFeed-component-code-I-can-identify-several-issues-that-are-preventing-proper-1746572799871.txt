Main Issues with the Current Shuffling Implementation

Inconsistent Shuffle Parameter Handling:

Your code is checking for URL parameters (shuffleSeed or shuffle) but isn't consistently applying the shuffle on normal browser refreshes
The shuffling logic only triggers when these URL parameters are explicitly present


Context Usage Problem:

You're importing ShuffleContext and extracting shuffleSeed, but this seed isn't automatically changing on page refresh
The seed is only used as a fallback when URL parameters aren't present


Cache Invalidation Issues:

The current implementation only invalidates the query when URL parameters are detected
Normal page refreshes don't trigger a new shuffle
